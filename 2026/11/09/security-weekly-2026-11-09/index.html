資安週報精選｜APT 套件驗證漏洞與修補

AI 協助整理 · 2026-11-09 · 2 分鐘閱讀

本期聚焦 APT 的高風險漏洞：適用條件、版本確認，以及修補前應注意的下載路徑。

本篇節選自 2026/11/02–11/08 的資安週報，於 11/13 重新核對官方來源。這是公開資訊精選，不是完整漏洞清單，也不表示讀者的系統已受影響。

本週先看：APT 安全更新

Canonical 於 11/4 公告 CVE-2026-109518。能操縱套件下載 HTTP 流量的攻擊者，在重試下載等條件成立時，可能使 APT 安裝惡意套件並取得 root 權限。官方評為 High，CVSS 4.0 為 7.7。

Ubuntu 22.04 LTS 及更新版本在預設設定下受影響；較舊版本則須檢查 Acquire::Retries 是否非零。公告提供修補，但不能據此認定所有系統已完成更新。

建議檢查順序

  1. 確認作業系統、APT 版本及套件來源。
  2. 對照官方修補表；例如 Ubuntu 22.04 的修補版本為 2.4.15ubuntu0.1。
  3. 依維護流程安裝更新，再確認實際安裝結果。HTTPS 可降低此下載路徑攻擊風險，但不應取代修補。

證據邊界： 本篇未確認野外利用狀態，也未檢查任何個別主機。

官方來源

  • Canonical：APT vulnerability fixes available（2026/11/04）
